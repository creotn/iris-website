Profile

Avatar Ring

64px avatar wrapped in a 2.5px gradient ring (#0B96D0→#00ACE4). Inner circle is #1C1C1E dark, initials in 20px bold white.

Verification Badge

Green "✓ Verified" badge uses rgba(0,200,122,.12) bg. Only shown after admin verification in the dashboard. Drives trust signals for customers.

Stats Cards

Three equal-width #1C1C1E cards in a flex row. Values are bold 16px white, labels 9px muted. Pulled from real job history.

Toggle Component

CSS toggle: #00C87A when on, #3A3A3C when off. Thumb slides on transition. Controls real-time notification preferences.

Working Hours

Days off shown in #DC3545 red. Mon–Fri and Sat have different schedules. Hours control dispatch eligibility per time slot.

Profile Header Gradient

Header uses linear-gradient(180deg, #1A1A2E, #111111) — a subtle blue-tinted dark that lifts the profile area above the plain screen background, giving visual depth.

Bank Account Row

Shows masked account number with last 4 digits and bank name. Tapping navigates to a dedicated bank settings screen with full add/change/verify flow.

Documents Section

Professionals must upload an ID and certification. The "✓ Verified" badge in green is set by admin from the dashboard. Unverified pros see an "Upload required" warning.

Available Now Toggle

The working hours card has a real-time availability override. Even during working hours, the professional can toggle offline instantly — useful for breaks or end-of-day.
